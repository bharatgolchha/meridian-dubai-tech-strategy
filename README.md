# Meridian — Systems Integration & Automation Strategy

A high-converting, premium B2B landing page tailored for a cutting-edge systems integration and technology strategy consultancy in **Dubai, United Arab Emirates**.

This page was built using advanced strategic market research of the Dubai multi-industry general enterprise landscape, focusing on solving the major integration pitfalls unique to Middle Eastern conglomerates.

## ✨ Features

- **Tailwind CSS Styling:** Modern dark theme featuring rich ink (`#0c0a09`) backgrounds, golden accents (`#b8812c`), and fine-tuned text treatments.
- **Enterprise-focused Copywriting:** Explicitly addresses local UAE pain points, such as "Best-of-Breed Legacy Traps," "The Talent Chasm," and local UAE personal data protection laws (PDPL) compliance.
- **High-Converting UX Elements:**
  - Floating responsive header with blurred glass backing (`backdrop-filter`).
  - Interactive "Consultation Scheduling" contact form with dynamic success states.
  - Interactive custom CSS scroll-reveal and smooth navigation.
  - Interactive dynamic visual mapping of the "Meridian Middleware Layer" showing data flow from input systems through iPaaS to downstream AI orchestration.

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/bharatgolchha/meridian-dubai-tech-strategy.git
   ```
2. Open `index.html` in any web browser to view the site live.

## 🛠️ Tech Stack

- **HTML5 & Vanilla Javascript** for lightweight, dependency-free interactions.
- **Tailwind CSS (via CDN)** for design utility and responsive layouts.
- **Google Fonts (Inter & Playfair Display)** for premium editorial and tech hybrid typography.
